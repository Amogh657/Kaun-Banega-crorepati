# Who Will Be the Millionaire? 🎮

A Python-based multiple-choice quiz game inspired by the Indian television quiz show **Kaun Banega Crorepati (KBC)**, the Indian adaptation of the *Who Wants to Be a Millionaire?* format.

The game allows players to answer randomly selected questions, earn increasing prize amounts, and use lifelines when they need help.

## Features

- Multiple-choice quiz questions
- Random selection of questions
- Increasing prize money for correct answers
- **50-50 Lifeline** – Removes two incorrect options
- **Audience Poll Lifeline** – Displays simulated audience poll results
- Questions stored separately in a JSON file
- Used lifelines are removed after use
- Option to continue answering questions until an incorrect answer is given

## Technologies Used

- Python
- JSON
- `random` module
